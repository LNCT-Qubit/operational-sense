# Operational Sense Web App

React + TypeScript + Vite frontend for Operational Sense, providing the landing/authentication page, technician portal, and supervisor review workspace.

## Scripts

Run from `apps/web`:

- `npm install` — install dependencies
- `npm run dev` — start the Vite development server
- `npm run build` — run TypeScript project check (`tsc -b`) and build production bundle (`dist/`)
- `npm run lint` — run ESLint across the web app
- `npm run preview` — preview the production build locally
