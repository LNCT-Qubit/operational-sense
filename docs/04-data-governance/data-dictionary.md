# Data Dictionary

Criticality assessment fields include `assessment_id`, `asset_id`, five integer scores, five rationale fields, `weighted_score`, `criticality_index`, `final_category`, `framework_version`, `weights_version`, `assessment_status`, `data_origin`, `assessor`, `assessment_date`, and `is_current`.

Required validation: scores 1–5; calculated weighted score 1.00–5.00; index 20.0–100.0; category in Low/Medium/High/Critical; one current approved record per asset. The companion scoring workbook contains the detailed 28-field definition set.
