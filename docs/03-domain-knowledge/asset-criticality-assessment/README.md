# Asset Criticality Assessment Deliverables

This folder contains the requested six deliverables plus the companion scoring workbook.

1. `Asset_Criticality_Assessment_Framework_Document.docx` — main framework document.
2. `Criticality_Assessment_Factors_and_Definitions.docx` — factor definitions and scoring scales.
3. `Asset_Criticality_Scoring_Matrix.xlsx` — full companion workbook with factors, scales, parameters, assessments, rationale, field definitions, source register, review log, and open issues.
4. `Criticality_Classification_Guidelines.docx` — classification rules, parameters, and operational review guidance.
5. `Representative_Asset_Assessment_Examples.docx` — illustrative assessment records and rationales.
6. `Criticality_Assessment_Field_Definitions.docx` — assessment field definitions and hierarchy alignment.
7. `Supporting_References_and_Source_Register.docx` and `.xlsx` — reference register, review log, and open issues.

## Important status note
The source framework is explicitly a **draft proposal**. Weights, bands, default time bands, and override rules require approval and site calibration. Examples are illustrative, not site data. The source artifacts are retained in `../source-artifacts/`.
