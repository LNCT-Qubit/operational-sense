# User Stories

- As a reliability engineer, I want to assess an asset instance so criticality reflects its real service and standby arrangements.
- As a reviewer, I want rationales and version history so I can reproduce and approve a result.
- As a retrieval user, I want relevant evidence with provenance so I can evaluate an answer.
- As a data steward, I want validation rules so synthetic, incomplete, and site-origin records are distinguishable.
