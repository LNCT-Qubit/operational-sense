# Functional Requirements

- FR-01: Maintain asset, equipment type, and equipment class identifiers.
- FR-02: Store criticality assessments as asset-instance records with history.
- FR-03: Validate five factor scores against the range 1–5.
- FR-04: Calculate weighted score, index, band, override floor, and final category deterministically.
- FR-05: Store rationales for scores of 4 or 5.
- FR-06: Store framework version, weights version, status, origin, assessor, and assessment date.
- FR-07: Expose criticality metadata for filtering/ranking without conflating it with case severity.
- FR-08: Preserve source provenance and allow reviewers to trace claims to sources.
