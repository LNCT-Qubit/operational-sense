# Non-Functional Requirements

- Reproducibility: same inputs and versions produce the same calculated result.
- Traceability: changes, sources, versions, and approvals remain auditable.
- Security: secrets are not committed; access controls are required before real plant data is used.
- Data integrity: schema constraints prevent invalid scores and duplicate current assessments.
- Maintainability: domain rules and APIs are documented and tested.
- Explainability: retrieval outputs show supporting evidence and abstain when evidence is inadequate.
