# User Personas

- Reliability engineer: compares asset consequence profiles and prioritizes maintenance attention.
- Maintenance planner: uses approved criticality tiers to inform preventive maintenance and spares reviews.
- Domain reviewer: verifies scores, rationales, source quality, and assumptions.
- Backend/AI engineer: consumes stable identifiers, schemas, and metadata.
- QA/data steward: validates imports, schema compliance, provenance, and reproducibility.
