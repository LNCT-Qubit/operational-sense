# Data Flow

1. Ingest approved documents or structured records.
2. Record source, license/access level, timestamps, and provenance.
3. Validate and normalize content; map equipment terms to taxonomy IDs.
4. Store structured entities and approved text chunks.
5. Retrieve candidate evidence through structured, graph, vector, or hybrid paths.
6. Rank and package evidence with source references.
7. Generate an answer only when evidence meets policy; otherwise state limitations or abstain.
8. Capture feedback and evaluation outcomes for review.
