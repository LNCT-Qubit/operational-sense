# High-Level Design

- Web app: user-facing asset, case, search, and feedback workflows.
- Backend: APIs, validation, authentication/authorization integration, persistence, and audit events.
- AI engine: ingestion, preprocessing, taxonomy mapping, retrieval, ranking, evidence packaging, and evaluation.
- Database: normalized entities, versioned assessments, cases, sources, and indexes.
- Data governance: schema validation, provenance manifests, anonymization, and quality reports.
