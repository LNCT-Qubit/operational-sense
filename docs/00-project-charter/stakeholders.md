# Stakeholders

- Domain research: definitions, taxonomy, framework rationale, and references.
- Backend and database: persistence, constraints, versioning, and API contracts.
- AI and retrieval: evidence retrieval, filtering, ranking, and abstention.
- QA and integration: validation, traceability, test coverage, and data quality.
- Operations, maintenance, safety, and production representatives: site calibration and assessment review.
- Workstream lead or supervisor: formal approval of the framework and changes.
