# Environment Setup

1. Install Git and the runtime/toolchains selected by the project.
2. Copy `.env.example` to a local `.env` and replace placeholders; do not commit `.env`.
3. Confirm the database, backend, web, and AI-engine versions once selected.
4. Configure dependencies in each service directory.
5. Run service-specific tests after they have been implemented.
6. Treat this repository as a scaffold until setup and CI instructions are finalized.
