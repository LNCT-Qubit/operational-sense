# Troubleshooting

- **Invalid score:** check that every factor is an integer from 1 to 5.
- **Unexpected category:** verify the framework/weights version, rounded index, and override rules.
- **Missing asset link:** reconcile asset/type/class IDs with the approved hierarchy.
- **Untrusted retrieval answer:** inspect source provenance, retrieval candidates, ranking, and abstention thresholds.
- **Import failure:** review schema version and the data-quality report.
- **Workflow does not run tests:** workflows are placeholders until real commands are configured.
