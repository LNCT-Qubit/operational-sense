## Candidate schema

- `public.equipment_class`: source IDs and class labels for Pumps, Motors and Compressors.
- `public.asset_node`: arbitrary-depth physical hierarchy using `parent_asset_id`.
- `public.m06_equipment_component_reference`: source-provenance map for Group 1 subsystem/assembly, component/maintainable-item and taxonomy labels. This is not an approved taxonomy table and does not create physical assets.

The migration uses `BIGINT GENERATED BY DEFAULT AS IDENTITY` for `asset_id` as a provisional choice because M04 Q09 leaves the ID strategy open. It deliberately fails if `public.equipment_class` or `public.asset_node` already exists. Do not bypass this guard; reconcile the migration with M05 instead of creating duplicate entities.

Hierarchy levels are not constrained to Plant/Area/System/Equipment/Component, because M04 says the hierarchy contract requires Group 1 approval. Subsystem labels remain descriptive reference metadata until Q01 is resolved.

## Run static checks

Requires Python 3.10+ and pytest.

```bash
python scripts/validate_package.py
python -m pytest -q
```

These checks validate package structure, CSV-to-source snapshot fidelity, key source identifiers, seed SQL presence, and SQL safety guardrails. They do not prove PostgreSQL syntax/runtime behavior.

## Run PostgreSQL tests

Requires PostgreSQL and `psql`. Use only a newly created, disposable database whose name contains `test`. The runner refuses to proceed without an explicit mutation opt-in and refuses if core target tables already exist.

```bash
export M06_TEST_DATABASE_URL='postgresql://user:password@localhost:5432/operational_sense_test'
export M06_ALLOW_DATABASE_MUTATION=YES
bash tests/postgres/run_clean_database_tests.sh
```

On Windows, run the script in WSL/Git Bash, or execute its steps manually with `psql`. Never use production credentials or a shared database.

The script applies the candidate migration in a transaction, loads the seed twice, runs SQL assertions and executes negative FK/self-parent/cycle tests in a transaction that rolls back its test nodes.
