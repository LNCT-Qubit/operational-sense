# Data dictionary

This is the candidate physical contract in `../sql/migrations/0001_m06_asset_hierarchy.sql`. It is implemented in SQL but remains provisional pending M05/Common Data Model review.

## `public.equipment_class`

| Column | Type | Constraint / meaning |
|---|---|---|
| `equipment_class_id` | `VARCHAR(32)` | Primary key; preserves source IDs `EQ-PUMP`, `EQ-MOTOR`, `EQ-COMP` |
| `class_name` | `TEXT` | Required nonblank source label; no canonical-name uniqueness constraint pending approval |
| `description` | `TEXT` | Required nonblank source description |
| `review_status` | `TEXT` | Required; default `PENDING_REVIEW`; controlled vocabulary pending approval |
| `source_sheet` | `TEXT` | Provenance sheet name |
| `source_row_number` | `INTEGER` | First source row for the class; must be greater than header row |

## `public.asset_node`

| Column | Type | Constraint / meaning |
|---|---|---|
| `asset_id` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | Candidate primary-key strategy; M04 Q09 remains open |
| `parent_asset_id` | `BIGINT NULL` | Self-reference; FK with `ON DELETE RESTRICT`; self-parent and cycles rejected |
| `asset_level` | `TEXT` | Required nonblank level; not restricted to a vocabulary until Group 1 approves Q01 |
| `asset_name` | `TEXT` | Required nonblank display name |
| `equipment_class_id` | `VARCHAR(32) NULL` | FK to equipment class; optional because M04 permits non-equipment hierarchy nodes |
| `model_label` | `TEXT NULL` | Descriptive model label; not a separate `EquipmentModel` entity in the M04 physical proposal |
| `model_is_illustrative` | `BOOLEAN` | Required, defaults `FALSE`; prevents an illustrative label being mistaken for verified model identity when set `TRUE` |
| `site_identifier` | `TEXT NULL` | Logical site identifier; scope/uniqueness unresolved |
| `status` | `TEXT` | Required nonblank text; defaults `PENDING_REVIEW`; controlled vocabulary pending approval |

## `public.m06_equipment_component_reference`

This M06-owned provenance table is a staging/reference map, not a claim that component taxonomy is approved or that subsystem labels are hierarchy nodes.

| Column | Type | Constraint / meaning |
|---|---|---|
| `reference_id` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | Primary key |
| `equipment_class_id` | `VARCHAR(32)` | Required FK to `equipment_class` |
| `equipment_class` | `TEXT` | Exact source class label |
| `subsystem_assembly` | `TEXT` | Exact source subsystem/assembly label |
| `subsystem_id_source_value` | `TEXT` | Exact source text: no subsystem ID is defined |
| `component_maintainable_item` | `TEXT` | Exact source component/maintainable-item label |
| `taxonomy_code` | `TEXT` | Exact source code; not automatically approved taxonomy |
| `source_sheet` | `TEXT` | Source sheet provenance |
| `source_row_number` | `INTEGER` | Original Excel row number |
| `model_information_note` | `TEXT` | Exact source note about models |
| `review_status` | `TEXT` | Defaults to `PENDING_REVIEW`; this is an implementation default, not a source approval field |

Constraints include PKs, class FKs, nonblank required text, unique source sheet/row, unique mapping tuple, parent FK, self-parent check, and a cycle-detection trigger. Class-name uniqueness, hierarchy-level vocabulary, asset-name uniqueness and parent-scoped uniqueness are deliberately not asserted while their semantics remain open.
